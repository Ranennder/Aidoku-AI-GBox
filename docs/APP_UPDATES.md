# Уведомление о новой версии

Начиная с Aidoku AI **0.9.17 (21)** приложение проверяет обновления при запуске и при возвращении из фона. Если в публичном списке Feather есть более новая совместимая версия, сверху появляется закрываемая плашка с номером версии и кнопкой **«Обновить»**.

Кнопка открывает страницу конкретного выпуска в браузере. Скачай IPA и установи его поверх приложения через Feather или GBox с прежним идентификатором и подписью, чтобы сохранить данные. Приложение не может само подписать и установить IPA. Старую версию заранее удалять не нужно.

Закрытие плашки действует до следующего открытия приложения. Центр управления и системные диалоги не запускают повторные проверки. При отсутствии интернета или ошибке сервера ничего не блокируется. Проверка идёт асинхронно, с таймаутом 10 секунд, без изменения размеров читалки.

Источник версий — существующий публичный [список Feather](https://raw.githubusercontent.com/Ranennder/Aidoku-AI-GBox/main/feather.json). Учитываются числовая версия, номер сборки и минимальная версия iOS. Переподпись приложения с другим bundle ID не мешает найти обновление: поиск использует постоянный идентификатор форка в списке. Ссылка ведёт только на выпуск Aidoku AI в `Ranennder/Aidoku-AI-GBox`.

Чтобы эта функция появилась в установленной **0.9.16 или более старой версии**, сначала обновись вручную до 0.9.17. После этого приложение сможет сообщать о следующих выпусках. Установка текущей 0.9.17 не должна показывать плашку о самой себе.

Выпуск 0.9.17 добавил уведомления об обновлениях; Google-входа в нём ещё не было. Актуальная настройка синхронизации для более новых версий описана в [HISTORY_SYNC.md](HISTORY_SYNC.md).
